# Plan 精选与行程展示版

版本：`2026-11-01-conversation-6`，候选协议版本 `3`。

## 部署与继续测试

1. 将同目录 `travel-companion.mjs` 全部复制，整体替换现有 Cloudflare Worker 代码并部署；原有 Secrets 与环境配置保留。
2. `/api/health` 应出现 `version: "2026-11-01-conversation-6"`、`candidatePoolContract: 3` 和 `mapResolveEndpoint: true`。
3. 强制刷新前端。之前的旅行需求和方案仍在本浏览器保存。点击“修改旅行需求”，按原需求重新生成，即可让每个国内城市完成新筛选；也可逐城在备选中重试。旧候选没有 AI 精选结果时，不会按原始搜索顺序展示。
4. 继续自由输入目的地，不针对长沙、衡阳或其他城市预设答案。

## 本轮交互与地图更新

- 自由输入上移到快捷修改建议下方。“根据讨论调整建议”直接提交当前想法并保留历史方案；另保留“先和 AI 讨论”。
- 截图与文档共用一个资料入口，“根据整理内容，吸收精华调整行程”先提取线索，再更新方案；提取内容不直接视为已核验事实。
- 全宽“进入每日行程”进入真实方案工作台；修复更新后按钮一直禁用的问题。
- 全程真实底图展示城市顺序与分段交通建议。每日真实底图展示具体景点与具体餐厅；菜品和泛指区域不假装成餐厅定位。绿色景点、棕色餐饮。
- 新增 `/api/map/resolve`，使用现有 `AMAP_WEB_KEY`，无需新增浏览器 Key。城市支持唯一匹配；同名景点或餐厅有歧义时不选第一个。国内位置匹配与开放/预约核验分开。
- Leaflet 与 OpenStreetMap 底图依赖网络；高德坐标转换后显示。虚线仅表示顺序，不是实际道路、铁路线路或已计算的导航路线。国外位置解析目前明确提示暂不支持。

## 保留的筛选逻辑

- 检索策划使用与 Plan 相同的 `thinking: disabled` 配置，增加时限与安全错误诊断。上一轮降级原因仍需查看实际服务日志确认，不能把参数修正当作已经证明的根因。
- 独立的 DS 筛选步骤读取全部有效候选，按明确偏好、兴趣关系、代表性、体验互补与地理分区做取舍；排除入口/停车场/同质分店等噪声。最多保留12个，数量少时不凑数。
- 这是模型按规则作出的可解释排序，不是训练好的固定评分模型、热榜或已验证的最优路线。后续以盲测反馈调整规则。
- 前台每次展示最多3个未安排精选备选，已经安排的地点在当天展示；待加入的明确选择额外保留。其余精选可换一组查看；原始候选保留在会话数据中，不直接堆到页面。
- 为每个国内城市逐一发现并筛选，再统一细化 Plan。任何城市失败明确保留草案/重试状态，不声称已完成筛选。
- 拒绝“历史人文地点”“地方生活街区”“特色餐饮区域”等占位行程。明确的交通、抵达或休息日可没有游览点。
- 每天的具体景点与推荐理由直接展示；当地风味和可选餐饮写当天 `local_food`，不强制每餐时刻。具体店铺必须匹配候选，未核验的菜品/区域建议明确标注。
- 生成后收起需求表单；核验、来源、交通、资料上传与示例工具折叠，保留主要的行程和调整操作。

## 验收重点

- 多城市行程中，每个国内城市都完成候选筛选，具体游览日有具体地点。
- 不再出现98条原始搜索结果；少量备选有推荐理由与取舍，不把搜索位置当推荐名次。
- 改兴趣/文字喜好后，观察地点组合与推荐理由是否合理变化；允许真正相关的重叠地点。

- 未加载新协议、精选失败和未知动态信息均应明确显示状态。

## 验证与边界

19项自动检查通过，外部接口使用模拟数据；浏览器验证自由输入更新至 V2、进入每日行程、当天景点与餐厅定位，以及切换日期后的标记更新。测试浏览器收到 OpenStreetMap 底图的访问限制图片，不能据此确认正式页面的底图可用；部署后需实际检查，若仍受限需配置合适的生产底图服务。模拟夹具不发布。

真实 DS/高德效果待部署后盲测。门票、开放时间、预约、真实道路路线及国外地图能力仍未接通完整核验。交通方式是建议，不代表已经确认可购班次或精确路程。

## V5 盲测修正

- 筛选失败自动重试一次，兼容 JSON 代码围栏；失败原因显示在该城备选中。真实服务失败根因尚待部署后的错误代码确认。
- 一起决定逐题填写并提交更新方案；可保留草案继续查看。
- 已匹配候选保留高德来源；每日泛称可点击补全具体地点，不能把自由活动或待选苗寨伪装成已定位。
- 全程为动态 SVG 手绘风格城市/Day 图；完整坐标按位置投影，缺失时明确降级为顺序示意，不绘制虚构行政轮廓。每日保留真实地图。
- 20项模拟检查通过；新版页面尚需实际浏览器与真实 DS/高德盲测验证。

## V6 对话与更新

- POI query/rank JSON 模式提示词补充显式 JSON 指令，满足提供商契约；HTTP 4xx 不原样重试。真实 400 恢复仍需部署后检查。
- 移除逐题大表单，统一发送框；最多两个关键问题，最新简短建议在输入前展示，长建议与历史默认折叠。生成更新方案是独立明确动作。
- 讨论与更新有即时等待状态、秒数；等待代表服务尚未返回，不伪造百分比或检索完成状态。
- 新版本每日卡片与上一版比较，变动日高亮，可查看原景点；新增/删除日与交通、补充建议改变另有提示。
- 自动检查23项，真实 DS 推荐与交互效果仍待盲测。

普通用户以快捷点选继续讨论；自由输入、上传、历史依据统一在更多定制中。备选每次3个，换方向按钮直接重新筛选，不先覆盖当前行程。
